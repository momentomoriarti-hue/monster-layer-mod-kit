[CENTER][SIZE=6][B]Monster Layer Mod Kit[/B][/SIZE]
[SIZE=4]Make your own opponents and bosses for Monster Layer — from videos, GIFs and pictures, no coding needed[/SIZE][/CENTER]

[B]Published with the developer's permission.[/B] The kit contains [B]no game files[/B]: you use your own copy of Monster Layer, and the kit never downloads the game.

[SIZE=5][B]What it is[/B][/SIZE]
A free, open-source set of Windows scripts that unpacks your copy of Monster Layer (Godot 4.3), adds new content to it and packs it back. My goal is simple: [B]I want people to download the kit and make content[/B] — new Lays, new bosses, new animations — and share it here.

[B]What you can make[/B]
[LIST]
[*][B]Custom Lays[/B] (opponents): one folder per Lay with a [ICODE]lay.cfg[/ICODE] and your media. Body (chest, genitals, sizes), up to 3 fixed traits, spawn chance (100 = as likely as one normal species), portrait, voice and sound muting.
[*][B]Custom Bosses[/B] that replace the dragon, with their own intro animation.
[*][B]Animations from your own videos, GIFs or pictures[/B] for thrust, pound, idle, free cum, egg, lose, orgasm and hypno. Several files per animation (picked at random), speed modifiers, auto-fit to the game's timings, Pleasure speed-up steps, FPS cap. Videos are converted automatically with FFmpeg.
[*][B]Mod settings[/B] for the whole mod: turn off the Pleasure speed-up, hide the normal Lays or the dragon, and more.
[*]Or edit the game itself in the Godot 4.3 editor — the kit gives you a ready project.
[/LIST]
Every config field is documented right in the example configs. The full guide is in the README (English and Russian).

[SIZE=5][B]Security — please read[/B][/SIZE]
A Godot [ICODE].pck[/ICODE] is not "just assets": it holds [B]the whole game's code[/B], and Godot has no sandbox. A modded [ICODE].pck[/ICODE] can do anything a program can do. So I built the kit so that sharing and playing mods can be done without having to trust the mod author.

[B]Principles of the kit[/B]
[LIST]
[*][B]Mods are shared as data, not code.[/B] [ICODE]pack-moded-source.bat[/ICODE] makes a [B]source zip[/B] that contains [B]only[/B] the configs (plain text) and the original videos, GIFs and pictures. No scripts, no programs, no game files. You can open every file, scan the zip with your antivirus or an online scanner (e.g. VirusTotal), or ask an AI agent to read it.
[*][B]All code is in one public, readable place[/B] — the Player Tools folder of the kit. Players build the mod themselves with it, so a mod author can't slip code into the build.
[*][B]Only official tools.[/B] Godot 4.3, GDRE Tools and FFmpeg are downloaded only from their official GitHub releases, only after asking, and each download is checked against a pinned SHA-256; a mismatch is deleted.
[*][B]The game is never downloaded and no [ICODE].exe[/ICODE] is ever shared.[/B] You always run your own, official [ICODE]Monster Layer.exe[/ICODE]. A Monster Layer mod never needs an [ICODE].exe[/ICODE].
[*][B]The kit's own game code doesn't use the network, doesn't run programs and doesn't touch files outside the game[/B], and is written so the checker below can verify that.
[/LIST]

[B]Player Tools[/B] (a separate folder with its own README, for players who just want to play mods):
[LIST]
[*][ICODE]build-mod.bat[/ICODE] — builds the mod's [ICODE].pck[/ICODE] from its source zip with the official Godot 4.3 and [B]your own game[/B]. It refuses the whole zip if it contains anything but configs, videos and pictures (scripts, scenes, [ICODE]@tool[/ICODE] scripts and editor plugins that Godot would run during the build, programs, archives, paths leaving the folder).
[*][ICODE]check-mod.bat[/ICODE] — checks a ready [ICODE].pck[/ICODE] [B]without running it[/B]: unpacks it, compares every script with your original game and flags program launching, network, loading code at run time, writing or deleting files outside the game, hidden programs and more. Verdict: LOOKS SAFE / WARNING / DANGER.
[*][ICODE]play-in-sandbox.bat[/ICODE] — plays a mod inside [B]Windows Sandbox[/B] (Windows 10/11 Pro): no internet, your game and the mod read-only, separate saves, everything wiped when you close it. Costs some FPS.
[/LIST]

[B]The safe path for players[/B]
[LIST=1]
[*]Get the mod as a [B]source zip[/B].
[*]Look inside and scan it with your antivirus.
[*]Build it yourself with [ICODE]build-mod.bat[/ICODE].
[*]Run it with your own, official [ICODE]Monster Layer.exe[/ICODE].
[/LIST]
[B]If you trust me and follow the instructions in the Player Tools folder, then most likely everything will be fine.[/B] "Most likely" because no checker can prove that something is 100% safe: the remaining risk is a media file crafted to attack a bug in FFmpeg or Godot itself, which your antivirus and Windows Sandbox cover. You don't have to trust me either: everything is plain-text scripts on GitHub — read them, or ask an AI agent to audit them (the repo has an [ICODE]AGENTS.md[/ICODE] made exactly for that).

[B]Staying careful with other people's mods[/B]
[LIST]
[*]Download mods only from the author's own thread or page, not from re-uploads.
[*][B]Never run an [ICODE].exe[/ICODE], [ICODE].bat[/ICODE], [ICODE].dll[/ICODE], [ICODE].ps1[/ICODE] or installer that comes with a mod.[/B] A mod is a [ICODE].pck[/ICODE] or a source zip, nothing else. Take the Player Tools only from the kit's GitHub page.
[*]Prefer source zips. If a mod exists only as a [ICODE].pck[/ICODE], check it with [ICODE]check-mod.bat[/ICODE] and play it in Windows Sandbox first. A mod that "needs" a [ICODE].pck[/ICODE] has hand-edited game code: be extra careful.
[*]Never ignore DANGER or REFUSED. WARNING means "read the report first".
[*]Back up your original [ICODE]Monster Layer.pck[/ICODE] and your saves ([ICODE]%APPDATA%\Godot\app_userdata\MonsterLayer[/ICODE]).
[/LIST]

[B]For mod authors[/B]
[LIST]
[*]Share the [B]source zip[/B] ([ICODE]pack-moded-source.bat[/ICODE]), and if you like the [ICODE].pck[/ICODE] from [ICODE]Moded Packed\Release[/ICODE] with its SHA-256. [B]Never upload the game's [ICODE].exe[/ICODE][/B] — it's copyrighted and players already have it.
[*]Because of these security rules, some things can never be part of a source zip: your own scripts, scenes, plugins or libraries. Everything a mod does has to be config fields and media that the kit's code reads. Missing a feature? Ask here — it can become a new config field for everyone.
[/LIST]
