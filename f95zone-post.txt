[SIZE=5][B]⚠ Be careful with other people's mods[/B][/SIZE]
A Monster Layer mod ([ICODE].pck[/ICODE]) holds the whole game's code and can do anything a program can. [B]Before you play a mod made by someone else, read the guide in Player Tools:[/B]
[CENTER][SIZE=4][URL='https://github.com/momentomoriarti-hue/monster-layer-mod-kit/tree/main/Player%20Tools'][B]➜ Player Tools: how to check and play other people's mods safely[/B][/URL][/SIZE][/CENTER]
In short: prefer mods shared as a source zip (only configs, videos and pictures) and build them yourself with the Player Tools; check a ready [ICODE].pck[/ICODE] before playing; use Windows Sandbox if you can; [B]never run an [ICODE].exe[/ICODE] or [ICODE].bat[/ICODE] that comes with a mod[/B].
For now, for security, mods made with the kit can contain only configs, pictures, GIFs and videos. If development continues, I'll try to add more features without losing players' trust.
